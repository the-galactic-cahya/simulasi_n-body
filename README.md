# Simulasi Gravitasi N-Body

## Deskripsi
Proyek ini merupakan simulasi numerik interaksi gravitasi tiga benda menggunakan Python. Simulasi menghitung percepatan gravitasi dan memperbarui posisi serta kecepatan benda menggunakan metode integrasi leapfrog.

## Requirements
- Python
- NumPy
- Matplotlib

## Metode Numerik
Simulasi menggunakan metode integrasi leapfrog untuk memperbarui posisi dan kecepatan benda akibat interaksi gravitasi.

## Cara Menjalankan
Instal pustaka yang diperlukan:

```bash
python -m pip install numpy matplotlib
```

Jalankan simulasi:

```bash
python main.py
```
